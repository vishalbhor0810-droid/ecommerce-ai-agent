# ShopEase Return Policy

## Overview

ShopEase allows customers to request returns for eligible products within 7 days of delivery. The product must be unused and should remain in its original condition and packaging. Customers can start a return request through their ShopEase account by selecting the relevant order and choosing the return option. After a return request is submitted, the product may be inspected before the return is approved. Products that are personalized, damaged due to customer misuse, or marked as non-returnable are not eligible for return.

## Return Conditions

Customers should include all original accessories, manuals, tags, and packaging when returning an eligible product. A return request submitted after the 7-day return period may be rejected unless an exception is approved by customer support. Items received in a damaged or incorrect condition should be reported as soon as possible. The return process may require photographs or other information to verify the condition of the product. Once the returned item passes inspection, the applicable refund or exchange process will begin.

## Return Process

To request a return, customers should open their order history and select the product they want to return. They must choose an eligible return reason and provide any information requested by ShopEase. A return pickup may be arranged depending on the customer's location and the product category. Customers should keep the pickup receipt or tracking information until the return is completed. Customers can contact ShopEase support if the return status does not update within the expected processing period.
